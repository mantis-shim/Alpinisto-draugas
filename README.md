# Alpinisto-draugas
Sveltekit web app made to get recommendations for your hikes also to keep track of your hiking inventory.

## Run (dev)

```sh
cp .env.example .env    # fill in ANTHROPIC_API_KEY
docker compose up       # http://localhost:5173, MongoDB on localhost:27017
```
